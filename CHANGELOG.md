# Changelog

## 0.2.1 — 2026-11-18

- Word highlight (cursor on an identifier) is now a pale fill with a thin border, so it no longer looks like a real selection. Hover and bracket-match fills moved off the selection colour too.

## 0.2.0 — 2026-11-18

- Everything around the editor (side bar, activity bar, tab strip, panel,
  terminal, status bar, title bar) now uses a slightly deeper cream
  (`#F6EDD9`), so the editor page stands out. The active tab keeps the
  editor's paper colour and reads as joined to it.
- Hover and selection tones in the side bar, tabs and status bar darkened
  to stay visible on the frame.

## 0.1.0 — 2026-10-30

- Initial release.
- One flat cream (`#FCF4E3`) across editor, side bars, activity bar, status
  bar, title bar, tabs, panel and terminal — no multi-tone patchwork.
- Warm ink text (`#332E27`, ~12:1 contrast) instead of low-contrast slate.
- Syntax and terminal ANSI colours from the Flexoki light ink palette
  (600 steps for text, 400 steps for terminal brights).
