# Changelog

## 0.1.0 — 2026-10-30

- Initial release.
- One flat cream (`#FCF4E3`) across editor, side bars, activity bar, status
  bar, title bar, tabs, panel and terminal — no multi-tone patchwork.
- Warm ink text (`#332E27`, ~12:1 contrast) instead of low-contrast slate.
- Syntax and terminal ANSI colours from the Flexoki light ink palette
  (600 steps for text, 400 steps for terminal brights).
